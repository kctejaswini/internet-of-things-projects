ESP32 Based Temperature and Humidity Monitoring System

Aim

To measure room temperature and humidity using an ESP32 board and DHT11 sensor.

Components Required

1. ESP32 Development Board
2. DHT11 Temperature and Humidity Sensor
3. Jumper Wires
4. USB Cable

Connections

DHT11| ESP32
VCC| 3.3V
DATA| GPIO 4
GND| GND

Working

- The DHT11 sensor measures temperature and humidity.
- ESP32 reads the sensor values.
- The measured values are displayed on the serial monitor.

Output

- Temperature: Displays room temperature in °C.
- Humidity: Displays humidity in %.

Applications

1. Smart Home Monitoring
2. Weather Monitoring
3. Indoor Environment Monitoring
4. IoT Projects

Conclusion

This project successfully measures room temperature and humidity using an ESP32 and DHT11 sensor.
